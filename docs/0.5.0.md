# LixinOS 0.5.0 · 双核并行与桌面会话

Rust 内核和 TCC 内核现在都能在两个 ARM64 vCPU 上同时运行用户进程。启动器默认分配两个 vCPU。一个进程做计算时，另一个进程可以在另一核继续运行，也可以通过管道唤醒等待数据的进程。共享内核服务仍通过公平锁依次访问。这个版本实现的是双处理器对称多处理（SMP）。启动器尚未提供区分物理核与同核硬件线程（SMT）的拓扑配置。

## 在本机查看双核

在 Mac 上运行以下命令，进入 LixinOS 后用 `cpuinfo` 查看上线的 vCPU 数量，用 `cat /proc/stat` 查看 `cpu0` 和 `cpu1` 各自的累计时间。

```sh
./scripts/run-kernel.sh --kernel rust --serial
```

把 `rust` 换成 `tcc` 可在同一块工作盘上运行自举内核。需要单核对照时，在启动命令前加 `LIXINOS_CPUS=1`。双核回归测试在客户系统里用 TCC 编译两个探针，核对计算结果，并检查管道的读写进程是否运行在不同的核上，直到读满 16,385 字节并收到 EOF。[双核回归测试](../scripts/test-smp.py) · [配对内核的启动和恢复](kernel-releases.md)

## 桌面与图形

- 安装对应会话包后，可从图形终端运行 `startgnome` 进入 GNOME Shell，或用 `startxfce4` 打开集成 Thunar、面板和时钟的 Xfce 会话。注销后可用 `desktop` 返回 LixinOS 桌面。三个入口共用工作盘。[桌面会话](native-desktop-sessions.md) · [Xfce 移植范围](../User/xfce/README.md)
- 两个内核都支持 Unix 域流套接字和共享内存。Wayland 客户端可以把像素缓冲区交给合成器；安装配套 Mesa 并使用支持 VirGL 的 QEMU 时，应用和 Mutter 可以通过虚拟 GPU 渲染。[Wayland](../User/wayland/README.md) · [图形后端](native-desktop-sessions.md)
- 物理仿真器可以运行三节倒立摆，在桌面暂停、单步或改变关节。MuJoCo 移植还提供命令行程序，可在客户系统中运行预编译模型。[物理仿真器](../User/physics/README.md) · [MuJoCo](../User/mujoco/README.md)

## 开发工具与 Agent

- 日常盘上可以并存 `node`（22.23.5）和 `node26`（26.13.1）。npm 和 npx 11.20.0 使用 Node 26，可通过校验证书的 HTTPS 安装 JavaScript 包。依赖外部 shell 的 npm 脚本仍受客户系统进程接口限制。[Node.js](../User/node/README.md) · [npm](../User/npm/README.md)
- 安装 Codex 后可在客户系统中运行全屏 `codex` 或非交互的 `codex exec`。配置工作区写权限后，构建与测试命令可在一次性 LixinOS 虚拟机里执行，并将改动写回项目。DeepSeek Harness 也提供 `dsh headless` 入口，可用会话 ID 接续任务。[Codex](../User/codex-exec/README.md) · [DeepSeek Harness](../User/dsh/README.md)
