# LixinOS 0.6.1 · ARM64 EL0 原生 Linux 执行与性能优化

两个内核新增 ARM64 EL0 原生访客执行与稀疏写时复制（CoW）虚拟地址空间（SVC 66），`linux-run` 可在 EL0 直接执行 ARM64 Linux 动态链接程序并由 trap 翻译系统调用；同步优化双内核热路径、事件驱动 IPC、Codex/DSH 交互与磁盘镜像校验。配对内核归档为 `kernel-2026-11-27.2`。

## 内核与原生 EL0 执行

- **原生 EL0 访客执行与稀疏 CoW 虚存（SVC 66）**：Rust 与 TCC 双内核实现 `LX_GUEST_SVC_NR`（SVC 66，ABI v1），支持低地址 `0x0c000000..0x40000000` 与高地址 `128..512 GiB` 稀疏地址空间、2 MiB slab 4 KiB 引用计数页分配、EL1 内快速按需零页与 CoW 缺页处理、只读段跨进程共享（`MAP_ALIAS`）和零拷贝共享内存（`MAP_SHARED`）。[guest.h](../Kernel/native/guest.h) · [guest.c](../Kernel/native/guest.c) · [guest-arch.S](../Kernel/native/guest-arch.S)
- **双内核热路径优化**：Rust 与 TCC 均支持构建盘只读文件零拷贝打开；TCC 内核新增 `SLEEPING` 任务状态与 `task_sleep_ms()` 修复 `idle_slice()` / `poll` / `sleep_ms` 的大内核锁空转，引入 64 字节块拷贝与像素倍增汇编，并移除 `smp_enter_preserved` 中冗余的 SIMD 现场保存。[fastmem.S](../Kernel/native/fastmem.S) · [task.c](../Kernel/native/task.c)

## Linux 兼容层与性能

- `linux-run` 启动时自动探测 SVC 66 进入原生 EL0 模式（设置 `LIXINOS_INTERP=1` 可回退解释器），结合事件驱动 `event_epoch` / `proc_event_epoch` futex 唤醒、256 KiB 大块 `file_io()` 与进程隔离/共享感知的 futex 键，显著缩短启动时间并降低内存占用。[linux-run](../User/linux-run/README.md) · [Linux 兼容层测试](../scripts/test-linux-run.py)
- **Chromium 与 WeChat 实测**：`content_shell` 本地页面首帧绘制由 24.3 s / 115.2 s 降至 **5.7 s**（Rust）/ **16.2 s**（TCC），HTTP 页面由 27.7 s / 127.3 s 降至 **7.3 s**（Rust）/ **19.5 s**（TCC），公开 HTTPS（`https://example.com/`）分别在 **9.9 s** / **30.4 s** 完成绘制；内核堆峰值由 1.4–1.7 GiB 降至约 222–614 MiB。WeChat 官方登录二维码解码与网络代理设置页在双内核上均通过验证。[Chromium 窗口测试](../scripts/test-chromium-window.py) · [WeChat 窗口测试](../scripts/test-wechat-window.py)

## 工具与客户端改进

- **Codex 与 DSH**：优化 LixinOS 上 `codex-exec` 的启动路径、SQLite 内存日志、只读模式与 TUI 输入；改进 `dsh` 无头对话、工作区与图形控制，并扩展桥接与隔离 shell 工作槽。
- **宿主机脚本**：[disk_image.py](../scripts/disk_image.py) 增加本地缓存编译的 FNV-1a 原生加速校验；新增 [run-alpine.sh](../scripts/run-alpine.sh) 启动脚本。
