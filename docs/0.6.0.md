# LixinOS 0.6.0 · 内核线程、虚拟内存与桌面应用

两个内核都可以按线程调度 pthread，还新增了按需分页的虚拟内存、交换空间、用户身份和文件记录锁。桌面增加了 Writer、PDF 阅读器、Code、FreeCAD 和 Chromium 窗口，图形程序支持拼音输入。配对内核归档为 `kernel-2026-11-26.7`。

## 内核

- 用当前 musl 适配层链接的程序，每个线程都占一个调度槽。线程共享进程的内存映射和文件描述符，各自有独立的 TID、栈和 TLS。在两个 vCPU 上，第一个工作线程会被放到另一个核。[内核线程](applications.md#kernel-scheduled-pthreads) · [线程回归测试](../scripts/test-kernel-threads.py)
- 用户内存按需分页，内存紧张时可以换出到交换镜像。[虚拟内存测试](../scripts/test-vm.py) · [交换空间测试](../scripts/test-swap.py)
- 新增用户与组身份、文件权限检查、文件记录锁、`#!` 脚本解释器、PCM 音频输出和启动画面。[身份测试](../scripts/test-identity.py)

## 桌面与应用

- **Writer**：基于 LibreOffice 25.2，可以编辑 Word 文档并导出 PDF。**PDF 阅读器**：基于 Xpdf 4.05。[Writer](../User/writer/README.md) · [PDF 阅读器](../User/pdfview/README.md)
- **Code**：图形文本编辑器。**FreeCAD 1.1.4**：可以使用 Sketcher 和 Part 工作台，`.FCStd` 文件能保存后重新打开。[Code](../User/code/README.md) · [FreeCAD](../User/freecad/README.md)
- **Chromium**：`content_shell` 通过 `linux-run` 和 Mutter 显示在 Wayland 窗口中。`linux-run` 可以运行 ARM64 Linux 动态链接程序。[Chromium](../User/chromium/README.md) · [linux-run](../User/linux-run/README.md)
- **字体与输入**：`fonts` 命令可以管理共享字体。GTK 和 Qt 程序支持 IBus 拼音输入。启动器使用新的图标集，也可以用拼音搜索应用。[字体](../User/fonts/README.md)
- **声音与游戏**：Doom 和视频播放器可以输出声音。新增《极品飞车 II SE》(`nfs2`)，以及开放素材的遭遇战游戏 `ra2`。[NFS2](../User/games/nfs2/README.md) · [ra2](../User/games/ra2/README.md)
- 其他新增：DeepSeek 图形客户端、MuJoCo 查看器、wasm3、动态链接器和账户管理。

## 启动器

启动器默认选中 Daily 工作盘，可以临时换用其他 `.img`。内存滑块范围为 2–16 GiB。在构建盘上，Rust 内核默认使用 6 GiB，至少需要 4 GiB；TCC 需要 24 GiB。

## 发布验证

两个内核都已归档为 `kernel-2026-11-26.7`。发布器从源码构建两个内核，并分别启动 Rust 串口版和 TCC 版，核对启动横幅和 `uname -r` 后才创建该标签。[配对内核的启动和恢复](kernel-releases.md)
