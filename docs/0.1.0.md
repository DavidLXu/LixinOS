# LixinOS 0.1.0 · 在系统内开发和迭代

相比 0.0.1，这一版把默认 Shell、编辑器、常用命令和 Agent 的调度逻辑移到用户态。你可以在 LixinOS 里编辑并重编这些程序，用 Git 跟踪项目，再让 Agent 提议和验证更改。 [0.0.1 版本说明](0.0.1.md)

## Agent 与系统升级

- `agent inspect` 继续从 guest 读取实际系统状态。`agent improve` 可以用旧测试和新增样例验证脚本，全部通过后启用新版，并保留上一版供 `agent rollback` 恢复。
- `agent run` 在指定项目中循环读取、暂存和测试 Python 脚本，默认最多调用 50 次工具。控制台显示当前工具、路径和结果。运行时可用 Ctrl+P 补充要求，或用 Ctrl+G 取消。
- 桥接把长请求分块发送，每块由 Mac 确认接收，避免 QEMU 在忙时丢掉请求数据。
- `agent tune` 可以调整 Agent 自己的调用预算和日志预览长度。设置通过测试并得到确认后生效，可用 `agent rollback-tune` 撤销。
- `agent system` 可跨目录暂存文本和二进制改动，并用 guest 的 TCC 编译候选程序。确认后整批写盘。最近一批可在重启后用 `agent system-rollback` 撤销。这个入口操作 LixinOS 的虚拟磁盘，Mac 负责转发模型请求。

## 用户态与开发工具

- 默认 Shell 改为 C 编写的 LixinOS Bash，安装在 `/bin/bash`，可在 guest 中重编。LXE1 继续使用固定的运行库入口，并增加了启动前台子进程和等待退出状态的接口。
- Nano、Kilo、`htop` 和常用命令在用户态运行。Kilo 提供 C/C++ 高亮和增量搜索，编辑器保存时可以检测其他窗格写入造成的冲突。
- 移植了基于 libgit2 的本地 Git，支持初始化、暂存、差异、提交和日志。Mac 端导出工具可以取出工作树及其 `.git` 目录。
- 加入 `lust`，可以在 guest 中把受支持的 Rust 子集编译成 LXE1，并直接运行生成的程序。

## 桌面、终端与网络

- 新增图形桌面，可用鼠标浏览文件、打开编辑器，并在多个终端会话间切换。矢量画板 `paint` 可以保存和重新打开自身生成的 SVG。
- 状态栏显示 CPU、内存、堆、栈、文件数和磁盘占用。`ls` 默认采用 `ls -lh` 的显示方式，交互输出用青色区分目录。
- Mac 可以通过本机 SSH 接入 LixinOS，重新连接时可恢复尚未关闭的终端。guest 新增 ARP、IPv4 和 TCP，以及通过 guest 网络连接远端的 SSH 客户端。

## 存储与升级

- QEMU 默认分配的内存从 128 MiB 增至 512 MiB。单个文件上限从 16 KiB 提升至 1 MiB。文件系统支持最多 1,048,576 个条目，每个快照槽为 64 MiB。最近 64 条命令可以跨重启保留。
- 首次启动时，启动器会迁移旧磁盘镜像，将校验有效的快照和历史复制到新布局。已知的旧版内置程序会随系统更新，用户自行编译的替换版本会保留。

启动方式、命令示例和测试入口见项目文档。 [项目 README](../README.md) · [中文系统手册](README.md)
