# LixinOS 0.4.0 · 日常桌面与应用开发

从 0.3.0 升级后，Rust 和 TCC 内核都可以使用同一块日常工作盘。在图形终端输入 `desktop`，从左侧 Dock 打开 Files、终端或 Apps。Apps 按用途列出当前盘已安装的程序，也可以用来找回已最小化的窗口。[桌面应用清单](applications.md)

## 桌面和终端

- 同一终端窗口里的多个标签可以各自运行命令。切到另一个标签后，原标签的任务继续执行。前台命令或管道可以用 Ctrl+C 中断。
- 任务管理器按 PID 显示进程，按秒采样 CPU 和内存，保留最近 60 个采样点。系统设置可以调整默认编辑器、时区、显示和 Agent 限额。
- 日历、秒表和支持拖动缩放的地图都可以在独立窗口打开。地图通过 Mac 桥接获取并缓存 OpenStreetMap 瓦片。右击桌面空白处可以更换壁纸。[桌面使用说明](../User/desktop/README.md)
- 窗口程序可以接收尺寸变化、键盘和指针事件，提交局部画面更新。`.win3` 还支持滚轮、粘贴和关闭请求，编辑器可以在退出前提示保存。[窗口协议](../User/desktop/README.md#editor-windows-win3)

## 应用商店和 Agent

打开 **Apps → 系统 → 应用商店**，可以从点子起步，也可以提供一份本地或 HTTPS 上的单文件 C 源码。Agent 在系统内修改代码和测试，用 TCC 构建程序。通过测试后可以预览、安装到 Apps，再继续修改或回滚。[应用商店说明](../User/app-store/README.md)

桌面 Agent 和终端的 `agent desktop` 使用同一份项目会话记录。重启后可以恢复任务，查看工具调用、源码差异和测试结果。连接 DeepSeek 时，桥接程序支持原生工具调用。[Agent 工作台](../User/desktop/README.md#desktop-app-workbench)

## 浏览器、编辑器和游戏

以下移植按需装到工作盘。已安装 NetSurf 3.11 的桌面可以从 Dock 打开图形浏览器，支持 HTTPS、图片、地址栏和浏览历史。本版也修正了苹果中国首页导航和按钮的 CSS 排版。[浏览器安装](../User/netsurf/README.md) · [页面实测](netsurf-apple-homepage.md)

| 软件 | 可以做什么 |
| --- | --- |
| Lite XL、dte | 在桌面窗口或终端里编辑代码。[Lite XL](../User/lite-xl/README.md) · [dte](../User/dte/README.md) |
| GTK 3 | 用 Mousepad 编辑文本、用 Nautilus 浏览本地文件、用 Ristretto 看图，或运行 Tetravex、Mahjongg 和 Mines。[GTK 移植说明](../User/gtk3/README.md) |
| Slint、Nano-X | 试用 Slint 软件渲染的控件和文本编辑器，或打开 Nano-X 自带的窗口管理器和文件浏览器。[Slint](../User/slint-demo/README.md) · [Nano-X](../User/nano-x/README.md) |
| 2048、ClassiCube | 在桌面合并数字方块，或进入离线单人方块世界，放置、拆除方块并保存地图。[2048](../User/games/2048/README.md) · [ClassiCube](../User/classicube/README.md) |

## 开发环境和数据

- 可选的 Node.js 22.23.5 能在系统内运行 JavaScript 和 ES 模块，支持异步文件读写。这版使用 V8 解释器，npm、TLS、`node:crypto` 和 WebAssembly 尚未包含。[Node.js 移植说明](../User/node/README.md)
- CPython 的协作线程可以在解释器检查点和已适配的阻塞调用处切换。`subprocess` 可以启动子进程，通过管道收发数据。[CPython 说明](../User/cpython/README.md)
- SFTP 支持在 Mac 和 LixinOS 之间传输项目目录。Git 可以分块读写大文件。Rust 内核保存快照时，可以复用目标快照中位置和内容均未变化的大文件扇区。[系统手册](../README.md#shell-and-disk)
- 启动器优先使用已初始化的日常工作盘。`python3 scripts/workdisk.py status` 可查看磁盘和备份，关机后可备份整盘，或从备份取回指定文件。[工作盘说明](../README.md#我的工作盘)
