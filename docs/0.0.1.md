# LixinOS 0.0.1 · 在系统里写出并运行第一个程序

这个版本把编辑器、编译器、用户态运行库和持久化文件系统接在了一起。在 Mac 上构建并启动一次系统后，你就可以在 LixinOS 里改源码、看运行结果，再关机保存工作。下次启动时，之前编译的 C 程序可以直接运行。

## 用一个程序体验这个版本

在 LixinOS 的 shell 输入：

```sh
echo '#include <stdio.h>' > hello.c
echo 'int main(void) { puts("Hello from LixinOS"); return 42; }' >> hello.c
tcc hello.c -o hello
./hello
```

终端会打印 `Hello from LixinOS` 和 `[exit 42]`。执行 `shutdown`，用同一块磁盘重新启动，再输入 `./hello`，就能运行上一次保存的机器码。想体验解释执行，可以用 `nano` 保存一段 Python 代码，再交给 `python 文件名.py`。

## 这个版本的范围

- **开发环境**：Nano 风格编辑器、MicroPython 交互与脚本执行、TinyCC 单文件 C 编译，以及 LXE1 程序的保存与加载。
- **交互与存储**：支持历史、补全、重定向和缓冲管道的 shell，带快照恢复的虚拟磁盘，以及可切换的双窗格控制台。
- **运行边界**：面向 QEMU 的 ARM64 虚拟硬件；shell 接受 ASCII 输入；每个文件最多 16 KiB。C 程序使用 LixinOS 的运行库接口。可选的模型服务通过宿主机桥接接入。

源码布局、LXE1 格式和磁盘恢复机制见[系统手册](README.md)。要复查编辑、编译、退出和重启恢复，可在 Mac 的项目目录运行 `python3 scripts/test-user.py`，测试会使用临时磁盘。
